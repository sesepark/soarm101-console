# 원격 추론 카메라 KeyError 수정 검증 — 2026-09-07

## 결론

수정 뒤 콘솔의 실제 원격 `RobotConfig`가 체크포인트 `rename_map`에서 카메라 이름을 구해
`base_0_rgb`와 `left_wrist_0_rgb`를 내보냈다. 검은 합성 영상으로 보낸 첫 관측을 포함한
10개 관측이 모두 action 50개짜리 청크로 돌아왔고, 이전의
`KeyError: observation.images.scene`는 재현되지 않았다.

클라이언트에서 잰 10회 왕복 지연 중앙값은 `371.23 ms`, 같은 10회의 서버 내부 추론 중앙값은
`304.38 ms`다.

## 변경 범위

원격 추론의 `build_remote_client_config()`만 체크포인트 map을 `_robot_config()`에 넘긴다.
각 카메라 role은 다음 규칙으로 환산한다.

```python
raw_key = f"observation.images.{role}"
policy_key = rename_map.get(raw_key, raw_key)
camera_name = policy_key.removeprefix("observation.images.")
```

따라서 체크포인트가 달라지면 원격 카메라 이름도 그 map을 따라간다. map에 없는 카메라는 원래
이름으로 남는다. 수집의 `build_record_config()`와 로컬 추론은 map을 넘기지 않으므로 계속
`scene`/`wrist`다.

서버로는 체크포인트의 `rename_map`을 계속 보낸다. 입력은 이미 정책 이름이어서 map의
`scene`/`wrist` source가 존재하지 않으며 rename processor는 무동작한다. 이 선택은
`build_remote_client_config()` 주석에 남겼다.

## 안전한 검증 방법

`RobotClient`를 만들지 않았고 follower와 카메라 장치에 `connect()`하지 않았다. 다만 콘솔이
실제로 만든 `RobotClientConfig.robot`으로 LeRobot robot 객체를 생성하고, 그 객체의
`observation_features`를 `map_robot_keys_to_lerobot_features()`에 통과시켰다. 장치 값 대신
관절 0과 검은 합성 영상을 넣었다. 반환 action은 길이만 확인하고 모두 버렸다.

실제 출력:

```text
ROBOT_CONNECTION=DISABLED (synthetic gRPC observations; returned actions discarded)
PROBE_INPUT=CONSOLE_REMOTE_ROBOT_CONFIG (synthetic images; no device connection)
ROBOT_CONFIG_CAMERA_KEYS=base_0_rgb,left_wrist_0_rgb
```

## 클라이언트 재접속 때 정책을 다시 읽는가

**매번 다시 읽는다. 캐시는 없다.** 같은 side server를 유지한 채 새 gRPC 채널이 실제
`RobotClient`처럼 `Ready`와 `SendPolicyInstructions`를 다시 보냈다. 서버 로그는 다음과 같다.

두 번째 연결도 첫 연결과 거의 같은 `130.7891초`를 썼다. 코드에서도 LeRobot 0.6.1
`PolicyServer.SendPolicyInstructions()`는 현재 checkpoint와의 동일성 검사를 하지 않고 매번
다음을 실행한다.

```python
self.policy = policy_class.from_pretrained(policy_specs.pretrained_name_or_path)
self.policy.to(self.device)
```

`Ready()`는 observation queue만 초기화하며 정책을 재사용하는 분기가 없다. 그러므로 600초
시한에서 최초 연결뿐 아니라 클라이언트를 새로 만들거나 재접속할 때마다 약 131~138초가 다시
빠진다. 여러 시행에서 side를 유지하는 것만으로는 적재 비용을 피할 수 없고, 서버 쪽 정책 cache
또는 이미 적재된 동일 spec을 재사용하는 변경이 별도로 필요하다.
